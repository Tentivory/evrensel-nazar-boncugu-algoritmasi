# 👁️ Evrensel Nazar Boncuğu Algoritması

## Dünyanın En Ciddi, En Bilimsel ve En Gereksiz Projesi

Bu depo, insanlığın binlerce yıldır çözemediği **nazar** sorununa kesin çözüm getirmek amacıyla geliştirilmiştir. 

Artık "nazar değmesin" demek yetmiyor. Bilim devreye girdi.

### Özellikler
- ✅ Tamamen çalışan Python kodu
- ✅ Abartılı bilimsel açıklamalar
- ✅ Nazar boncuğu gücünü isim uzunluğu, doğum yılı ve o anki ruh haline göre hesaplar
- ✅ Hiçbir şeyi çözmez ama çok güven verir
- ✅ %100 organik, GDO'suz, yerli ve milli algoritma

### Nasıl Çalıştırılır?
```bash
python nazar_boncugu.py
```

Sonra soruları cevapla, nazar seviyen hesaplansın. Eğer çıkan sonuç kötüyse, bu depodan çık ve gerçek bir nazar boncuğu al.
